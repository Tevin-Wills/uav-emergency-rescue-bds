# interfaces

**Type:** Shared package
**Responsibility:** Custom ROS 2 message definitions shared across more than one module.

## Overview

Custom message types used by multiple packages are defined here so type definitions live in
one place and avoid circular dependencies. Built via `rosidl_generate_interfaces` (see
`CMakeLists.txt`). Field-level documentation and the full topic map are in
`interfaces/message_formats.md` and `interfaces/ros2_topics.md` at the repo root.

## Structure

```
interfaces/
├── package.xml
├── CMakeLists.txt
├── msg/        # Custom message definitions (.msg)
├── srv/        # Reserved for service definitions (none defined yet)
└── README.md
```

## Messages (`msg/`)

| Name | Fields | Used by |
|------|--------|---------|
| `EmergencyCoordinate.msg` | `std_msgs/Header header`, `float64 latitude`, `float64 longitude`, `string source_id`, `string raw_message` | published by `beidou_short_message` on `/target/emergency_coordinate`; consumed by `qgc_control`, `path_planning` |
| `SimulatedRtcm.msg` | `std_msgs/Header header`, `uint8 sequence_id`, `uint8 fragment_id`, `bool fragmented`, `uint16 length`, `bool correction_available`, `float32 correction_age_sec`, `float32 correction_quality`, `string correction_source`, `float32 gnss_noise_std_m` | internal to `rtk_positioning` on `/rtk/simulated_rtcm` (simulated RTCM correction stream) |

## Services (`srv/`)

None defined yet. The `srv/` directory is reserved for future service types (none are
currently generated by `CMakeLists.txt`).
